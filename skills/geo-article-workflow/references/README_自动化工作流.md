# 工作流总览

> 本文只放「一张流程图 + 目录结构 + 索引」。**每一步怎么执行，见 `步骤0`~`步骤4`**；
> 流程骨架与红线见 `SKILL.md`。

## 整体流程

```
 用户给出生文项目（项目名 / 问题集 / 约稿需求）
        │
        ▼
 [步骤 0] 项目初始化 ── create_project.py / ima_download.py ── 用户确认
        │
        ▼
 [步骤 1] 生文提示词生成 ── 主会话定死变量组合 ── 子代理写 生文prompt<N>.md
        │                                        （任务书：build_writer_kit.py）
        ▼
 [步骤 2] 文章生成 ── 主会话写事实卡 ── 子代理写 文章/<主标题>.md   ← 成本大头
        │                              （开跑前：check_budget.py + 用户确认）
        ▼
 [步骤 3] 审查校对 ── check_articles.py 全量校验 ── 主会话直接小修 ── 汇总表
        │
        ▼
 [步骤 4] 文档导入 ── 飞书 / 腾讯文档 ── 「优化问题 → 链接」汇总表
```

## 目录结构规范（每个项目）

```
<项目名>/
├── 问题集/
│   ├── <项目名>生文公共prompt.md        # 文章生成规则
│   ├── <项目名>文章校对提示词.md         # 审查校对规则
│   ├── feishu_config.json / feishu_tokens.json
│   ├── tencent_config.json
│   ├── <问题目录1>/
│   │   ├── 生文prompt参考.md
│   │   ├── 变量组合对照表.md
│   │   ├── 生文提示词/生文prompt<N>.md
│   │   └── 文章/*.md                    # 文件名 = 主标题
│   └── <问题目录2>/ ...
├── 知识库/
│   ├── <产品信息>.docx / <竞品配置表>.xlsx / <品牌规范表达>.docx
│   └── 图片/ 或 场景图/
└── 需求和参考/
    ├── <约稿需求>.docx
    └── <参考prompt>.docx
```

## 新项目接入清单

1. 按上面的目录结构创建项目目录（或跑 `scripts/create_project.py`）。
2. 准备知识库文档：产品信息、竞品配置、品牌规范表达、文章注意事项、图片。
3. 为每个问题编写 `生文prompt参考.md`。
4. 编写 `<项目名>生文公共prompt.md`、`<项目名>文章校对提示词.md`。
5. 按需选择导入平台并填好配置：
   - 飞书：复制 `feishu_config_template.json` → `feishu_config.json`，建好文件夹并填 `folder_map`，完成 OAuth 授权。
   - 腾讯文档：复制 `tencent_config_template.json` → `tencent_config.json`，填 `client_id/access_token/open_id/target_folder_id`。
6. 按步骤 0→4 执行，每步结束让用户确认。
