# 步骤 0（前置）：项目初始化

> **何时读**：接到一个新的生文项目、或不确定项目目录/知识库是否就绪时。
> 读完本文回到 SKILL.md 的流程骨架继续。

---

## 一、判断项目是否已存在

检查 `cwd/<项目名>/`（或用户指定的项目目录）是否存在：

- **不存在** → 执行第二节创建骨架。
- **已存在**（老项目追加轮次）→ 跳过创建，只核对第四节的输入是否齐全，并确认历史文件保留策略。

## 二、创建项目骨架

```bash
python scripts/create_project.py "<项目名>" \
  --questions "问题1,问题2,问题3,问题4,问题5" \
  --workspace . \
  --config-template templates/feishu_config_template.json \
  --tencent-config-template templates/tencent_config_template.json
```

只使用飞书或只使用腾讯文档时，可以只传对应的 `--config-template`。

## 三、目录结构规范

```
<项目名>/
├── 问题集/
│   ├── <项目名>生文公共prompt.md        # 文章生成规则
│   ├── <项目名>文章校对提示词.md         # 审查校对规则
│   ├── feishu_config.json               # 飞书配置（按项目修改）
│   ├── feishu_tokens.json               # 飞书 OAuth token（自动生成）
│   ├── tencent_config.json              # 腾讯文档配置（按项目修改）
│   ├── <问题目录1>/
│   │   ├── 生文prompt参考.md
│   │   ├── 变量组合对照表.md
│   │   ├── 生文提示词/生文prompt<N>.md
│   │   └── 文章/*.md                    # 文件名 = 主标题
│   └── <问题目录2>/ ...
├── 知识库/
│   ├── <产品信息>.docx / <竞品配置表>.xlsx / <品牌规范表达>.docx
│   └── 图片/ 或 场景图/                 # 供文章引用的真实图片
└── 需求和参考/
    ├── <约稿需求>.docx
    └── <参考prompt>.docx
```

## 四、从 IMA 下载知识库

先确认用户已配置凭证（`~/.config/ima/client_id`、`~/.config/ima/api_key` 或环境变量），然后：

```bash
python scripts/ima_download.py "<知识库关键词>" "<项目名>/知识库"
```

脚本会递归下载到 `知识库/`，图片按原目录结构放入图片子目录。
IMA 接口的完整参数与错误码见 `references/IMA知识库下载流程.md`。

## 五、向用户确认/收集的输入

缺少时提醒用户按规范补齐：

- 项目名、优化问题列表（问题目录）
- 每个问题的 `生文prompt参考.md`
- `<项目名>生文公共prompt.md`
- `<项目名>文章校对提示词.md`
- `需求和参考/` 下的约稿需求、参考prompt、针对性强化prompt
- `知识库/` 下的产品信息、竞品配置、品牌规范表达、文章注意事项、图片
- 飞书：`feishu_config.json` 的 app_id/app_secret、folder_map、image_dir
- 腾讯文档：`tencent_config.json` 的 client_id/access_token/open_id/target_folder_id

## 六、完成标准

在开始步骤一之前，**必须让用户确认项目初始化完成**。
