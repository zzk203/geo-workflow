# 步骤 4：文档导入（飞书 / 腾讯文档）

> **何时读**：文章已校对完成，要交付为在线文档时。按用户指定平台读对应小节即可。

---

## 4A. 飞书导入

**输入**：`问题集/feishu_config.json`（或 WSL 版 `feishu_config_wsl.json`）、本次新增文章列表、`scripts/feishu_import.py`。

**输出**：可编辑的飞书文档链接，图片自动上传并插入。

### 执行步骤

1. **生成白名单**（只导入本次新增，避免重复）：

   ```bash
   python scripts/make_whitelist.py 问题1 "2026年xxx.md" "2026年yyy.md" --output whitelist_new.json
   ```

   ⚠️ **白名单里的文件名必须带 `.md` 扩展名**。漏掉扩展名时脚本会逐个报「文件不存在」，最后输出「没有找到待导入的文件」而不报错。

2. **导入前先检查 token 是否有效**：

   ```bash
   python scripts/check_feishu_token.py -c feishu_config_wsl.json
   ```

   - `[VALID]` → 可以继续。
   - `[MISSING]` → 先完成 OAuth 授权。
   - `[INVALID]` → token 失效，需重新授权。

   注意：`tenant_access_token` 即使能通过部分 API 校验，导入时仍可能返回 `mount_no_permission`；**必须使用 `user_access_token`**。

3. **运行导入**：

   ```bash
   python scripts/feishu_import.py -c feishu_config_wsl.json -w whitelist_new.json
   ```

### 坑位

- **WSL/路径**：配置里是 Windows 路径时，复制一份 `feishu_config_wsl.json`，把 `base_dir`、`image_dir` 改成 Linux 路径（`/mnt/c/...`）再用 `-c` 指定。
- **OAuth**：token 过期时脚本会在后台起一个 `localhost:8080` 回调服务并打印授权链接。用它做**后台任务**运行，把链接交给用户，等用户确认授权后再继续——脚本最长等待 15 分钟。
- **图片文件名含半角括号**（如 `xxx_fn(小).jpg`）会被 Markdown 的 `![](...)` 在第一个 `)` 处截断，导致图片路径失效。导入前用校验脚本扫一遍，改换成不含括号的等价图。
- 导入完成后向用户输出「优化问题 → 飞书文档链接」汇总表，并落一份记录文件。

## 4B. 腾讯文档导入

**输入**：`问题集/tencent_config.json`（模板 `templates/tencent_config_template.json`）、`scripts/tencent_import.py`、本次新增文章目录。

**输出**：可协作编辑的腾讯文档链接，图片随 docx 一起嵌入。

### 执行步骤

1. 配置需提供：`client_id`、`access_token`、`open_id`、`target_folder_id`、`permission`。
2. 先确认目标文件夹 ID：

   ```bash
   curl -H "Access-Token: $TOKEN" -H "Client-Id: $CLIENT_ID" -H "Open-Id: $OPEN_ID" \
     "https://docs.qq.com/openapi/drive/v2/folders/?limit=50"
   ```

3. 运行导入：

   ```bash
   python scripts/tencent_import.py \
     -c 问题集/tencent_config.json \
     --articles "问题1/文章" "问题2/文章" ... \
     --image-dir "知识库/图片素材"
   ```

### 坑位

- 脚本会先把 `.md` 转成带图片的 `.docx`，再导入为**原生在线文档**。不要用 `uploadType=drive`，否则生成的是只读云盘文件。
- 转 docx 是因为腾讯文档的本地文件导入接口按 Office 文件处理，不直接接受 `.md`；转换时会解析 `**加粗**` 并统一设为纯黑文字颜色。
- 若目标是空间目录且匿名链接仍只读，改导入到个人云盘目录，以保证「获得链接的人可编辑」生效。
- 导入完成后输出「优化问题 → 腾讯文档链接」汇总表。
