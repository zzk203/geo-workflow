# 成本模型与度量

> **何时读**：想搞清楚"这轮花了多少钱、花在哪一步"、或要验证一次优化到底省了多少时。

---

## 一、定价（deepseek-flash，CNY / 百万 token）

| 项 | 平峰 | 高峰 |
|:--|--:|--:|
| cache 未命中 input | 1.0 | 2.0 |
| cache **命中** input | 0.02 | 0.04 |
| output | 4.0 | 8.0 |

两个直接结论：

1. **命中价约为未命中价的 1/50**，所以"重新建立上下文"本身很便宜；
2. **输出最贵**（是未命中 input 的 4 倍），所以省钱的杠杆主要在"少输出、少轮次"。

## 二、币种陷阱（最容易看错的地方）

`~/.dsh/storages/cost-meter/ledger.json` 里 `days[<日期>].cost` 字段是 **USD**，
要乘以 `config.exchangeRate`（本机 7.2）才是人民币。

把 ¥1.32 当成真实花费会少算 7.2 倍——实际是 **¥9.5**。
同理，`prices.models.deepseek-flash` 里的 `cacheMiss / cacheHit / output` 是 **CNY / 百万 token**，不要混用。

## 三、查账户余额（权威来源）

```bash
KEY=$(python3 -c "import re;print(re.search(r'DEEPSEEK_API_KEY[:\s]+(\S+)',open('$HOME/.dsh/.credentials.yaml').read()).group(1))")
curl -s https://api.deepseek.com/user/balance -H "Authorization: Bearer $KEY"
```

返回 `balance_infos[].total_balance` 即当前可用余额（CNY）。
直接跑 `scripts/check_budget.py` 会把余额、今日已花、本批预估、风险等级一起算好。

> `ledger.json` 里的 `balanceRef.total` 不是剩余余额，别拿它当余额用。

## 四、按"主会话 / 子代理 / 步骤"归因

每个会话落在 `~/.dsh/sessions/<cwd-slug>/<session-id>/session.v4.jsonl.zstd`：

- **首行**是 session header：`origin`（`subagent` 表示子代理）、`parentSession`、`delegationDepth`、`createdAt`。
- **每个 `assistant/message`** 的 `data.usage` 给出 `inputTokens` / `outputTokens` / `cacheReadTokens` / `cacheWriteTokens`。
  ⚠️ 注意是 `data.usage`（嵌套），不是顶层 `usage`——按顶层取会全部拿到 0。
- 子代理属于哪个步骤，可以看它第一条 `agent/inbox/spliced` 里的任务书首句。

可直接复用这段统计：

```python
import subprocess, json, glob, os, time, datetime, collections

MISS, HIT, OUT = 1.0, 0.02, 4.0          # CNY / M token
def cny(i, c, o): return (i*MISS + c*HIT + o*OUT) / 1e6

day = datetime.date(2026, 9, 28)
lo = time.mktime(day.timetuple()); hi = lo + 86400

rows = []
for p in glob.glob(os.path.expanduser("~/.dsh/sessions/*/*/session.v4.jsonl.zstd")):
    if not (lo <= os.path.getmtime(p) < hi):      # 只统计当天，避免解压几百个文件
        continue
    raw = subprocess.run(["zstd", "-dc", p], capture_output=True, timeout=180).stdout.decode("utf-8", "replace")
    hdr = None; i = c = o = calls = 0; first = ""
    for line in raw.splitlines():
        if not line.strip(): continue
        try: obj = json.loads(line)
        except Exception: continue
        if hdr is None and obj.get("type") == "session": hdr = obj
        u = obj.get("usage") or (obj.get("data") or {}).get("usage")
        if u:
            i += u.get("inputTokens", 0); o += u.get("outputTokens", 0)
            c += u.get("cacheReadTokens", 0); calls += 1
        if not first and obj.get("type") == "agent/inbox/spliced":
            for it in (obj.get("data") or {}).get("inserted") or []:
                for cc in (it.get("content") or []):
                    if cc.get("type") == "text" and cc["text"].strip():
                        first = cc["text"][:500]; break
                if first: break
    if hdr: rows.append((hdr.get("origin"), first, calls, i, c, o, cny(i, c, o)))

sub = [r for r in rows if r[0] == "subagent"]
for g in ("①生文prompt生成", "②文章生成", "③超字数裁剪"):
    key = {"①生文prompt生成": "生文prompt撰写员", "②文章生成": "汽车内容作者", "③超字数裁剪": "内容编辑"}[g]
    grp = [r for r in sub if key in r[1]]
    print(g, len(grp), "个", f"¥{sum(r[6] for r in grp):.2f}",
          f"调用{sum(r[2] for r in grp)}", f"输出{sum(r[5] for r in grp):,}")
print("子代理合计", len(sub), "个", f"¥{sum(r[6] for r in sub):.2f}")
print("主会话合计", len(rows)-len(sub), "个", f"¥{sum(r[6] for r in rows if r[0]!='subagent'):.2f}")
```

## 六、验收口径

优化后用同一脚本对比，并同时看质量指标：

| 指标 | 基线 | 目标 |
|:--|--:|--:|
| 文章子代理 ¥/个 | 0.42 | ≤ 0.15 |
| 每次调用平均输出 | 1,600 | ≤ 900 |
| 每代理调用次数（3 篇） | 42 | ≤ 12 |
| 子代理合计（36 篇） | 6.94 | ≤ 2.5 |
| 校验通过率 | 36/36 | 不得下降 |

**只看成本下降、不看校验通过率的优化是失败的优化。** 每次改完都要跑一次全量校验做对照。
