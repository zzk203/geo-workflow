# 各步骤输入输出速查表

## 生文提示词生成

| 角色 | 内容 |
|:---|:---|
| **公共工具** | `生文prompt生成提示词_本地llm.md`（项目根目录） |
| **项目输入** | 各问题的 `生文prompt参考.md` |
| **项目输入** | 各问题的 `变量组合对照表.md`（首次为空） |
| **可调参数** | 每问题生成几个prompt、变量维度偏好 |
| **输出** | `生文提示词/生文prompt<序号>.md` + 更新 `变量组合对照表.md` |

## 文章生成

| 角色 | 内容 |
|:---|:---|
| **公共规则** | 严格的基于知识库、禁用词、格式要求（见 `步骤2-文章生成.md`） |
| **项目输入** | `<项目名>生文公共prompt.md` |
| **项目输入** | 各问题的 `生文提示词/生文prompt<序号>.md` |
| **项目输入** | `知识库/` 所有参考文档 |
| **可调参数** | 文章字数、标题字数、图片占位符格式 |
| **输出** | `文章/<主标题>.md` |

## 文章审查校对

| 角色 | 内容 |
|:---|:---|
| **公共规则** | 14条易错表述纠正规则、禁用词检查、数据校验 |
| **项目输入** | `<项目名>文章校对提示词.md` |
| **项目输入** | `需求和参考/<约稿需求>.docx` |
| **项目输入** | `知识库/` 参考文档 |
| **输出** | 直接修改文章 + 修改汇总表 |

## 飞书导入

| 角色 | 内容 |
|:---|:---|
| **公共脚本** | `自动化脚本/feishu_import.py`、`自动化脚本/check_feishu_token.py` |
| **公共模板** | `自动化脚本/feishu_config_template.json` |
| **项目输入** | `feishu_config.json`（按项目填写） |
| **项目输入** | `feishu_tokens.json`（OAuth 授权生成） |
| **项目输入** | `文章/` 目录下的 `.md` 文件 |
| **可调参数** | `image_handling`、`image_dir`、`folder_map` |
| **前置检查** | `python scripts/check_feishu_token.py -c feishu_config_wsl.json`，确认 `[VALID]` 后再导入 |
| **输出** | 飞书文档链接 + 图片自动上传 |


## 腾讯文档导入

| 角色 | 内容 |
|:---|:---|
| **公共脚本** | `scripts/tencent_import.py` |
| **公共模板** | `templates/tencent_config_template.json` |
| **项目输入** | `tencent_config.json`（按项目填写） |
| **项目输入** | `文章/` 目录下的 `.md` 文件 |
| **可调参数** | `target_folder_id`、`image_dir`、`organize_by_question`、`permission` |
| **前置检查** | 确认 `client_id`、`access_token`、`open_id` 有效 |
| **输出** | 腾讯文档在线链接（可协作编辑） |

## 新项目接入清单

1. 按目录结构规范创建项目目录
2. 准备知识库文档（产品信息、竞品配置、品牌规范、注意事项）
3. 为每个问题编写 `生文prompt参考.md`
4. 编写 `<项目名>生文公共prompt.md`
5. 编写 `<项目名>文章校对提示词.md`
6. 按需选择导入平台：
   - 飞书：复制 `feishu_import.py`、`check_feishu_token.py` 和 `feishu_config_template.json` → 改为 `feishu_config.json`，在飞书创建对应文件夹并填入 `folder_map`，完成飞书 OAuth 授权。
   - 腾讯文档：复制 `tencent_import.py` 和 `tencent_config_template.json` → 改为 `tencent_config.json`，填入 `client_id/access_token/open_id/target_folder_id`。
7. 按流程四步执行；导入前分别检查对应平台 token/凭证有效。
