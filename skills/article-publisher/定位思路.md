# 可复用定位思路（Playwright 自动化经验）

本文记录在「多平台文章发布」过程中沉淀的通用定位/操作思路，新增平台或脚本失败时优先参考。

## 1. 内容管理页定位文章

- 优先使用平台自带的「搜索框」定位，而不是翻页。
- 搜索框通用操作：
  1. 先 `click()` 输入框，再 `fill(关键词)`；
  2. 等待 300～500ms，让 React 受控组件提交值；
  3. 点击搜索图标；
  4. 再按 `Enter` 作为兜底（部分平台只点图标不生效，只按 Enter 也不生效，两者组合最稳）。
- **必须同时按日期过滤**：传入 `--date YYYY-MM-DD`，在候选卡片中匹配 `YYYY-MM-DD` 或 `MM-DD`，避免选中同名旧文章。
- 如果搜索不稳定，改用**短关键词**（取标题中 `：`/`？` 后的唯一片段），不要用完整长标题。
- 如果搜索仍失效，退回**分页收集**：先收集第 1 页，再点第 2、3 页，把所有卡片文本→链接合并后匹配。

## 2. 列表卡片与“修改”入口

- 列表里的“修改”不一定是 `<button>`，常见是 `<span>` 或 `<a>`；用 `getByText('修改', { exact: true })` 定位。
- 如果页面有吸顶 header/浮层遮挡，点击时报 “intercepts pointer events”，用 `click({ force: true })` 绕过。
- 有些平台点“修改”会在**新标签页**打开编辑页：先 `context.waitForEvent('page')` 再点击。
- 文章卡片不一定有可直接用的 `<a href>`：
  - 今日头条：`.article-card-bone a` 有公开链接。
  - 百家号：`a[href*="baijiahao.baidu.com/s?id="]` 有公开链接。
  - 易车：`h5.title a[href*="news.yiche.com/hao/wenzhang/"]` 有公开链接。
  - 懂车帝：列表标题没有 href，但点击标题会在新标签打开公开文章页 `https://www.dongchedi.com/article/{id}`，可直接抓新标签 URL。
  - 汽车之家：列表标题 `<a>` 直接指向 `club.autohome.com.cn/bbs/thread/...`。

## 3. 编辑页标题与保存

- 标题输入框常见是 `textarea`，placeholder 形如“请输入文章标题（2～30个字）”。
- 保存按钮通常是「发布」或「保存修改」；修改已发布文章后一般会进入“修改审核中”。
- 修改后等待跳转到文章列表页（如 `/graphic/articles`）或出现成功提示即可。

## 4. 封面/弹窗类流程

- 多个封面区块可能共用同一个 class（如易车 `.article-cover`），必须用文字过滤到目标区块：
  ```js
  page.locator('.article-cover').filter({ hasText: '*封面图' })
  page.locator('.article-cover').filter({ hasText: '*竖版封面图' })
  ```
- 上传图片后可能出现“裁剪/模板”弹窗：
  1. 点击上传区域（触发全局 filechooser 自动填图）；
  2. 等“完成裁剪”出现并点击；
  3. 在模板弹窗中点第一个模板图；
  4. 点「确定」/「保存」。
- 如果图片已默认选中但点击“确定”不生效，**先点击一次取消选中，再点击一次重新选中**，让 React 状态真正注册。
- 如果上传后没有出现裁剪弹窗，先检查目标封面是否已经设置（出现“更换”）；已设置则不要重复操作。
- 弹窗计数不要用 `[role=dialog], .el-dialog, .el-dialog__wrapper` 直接数，因为同一个弹窗可能匹配多个元素；应判断关键文本/按钮是否存在。

## 5. 剪贴板与粘贴

- Linux 下不要依赖 PowerShell/xclip，直接用浏览器 `navigator.clipboard`：
  - 写入：`new ClipboardItem({ 'text/html': ..., 'text/plain': ... })`
  - 读取：`navigator.clipboard.read()` 取 `text/html`
- 需要在 `browser.newContext()` 后 `grantPermissions(['clipboard-read','clipboard-write'])`。
- **优先使用本地中转文件**：`setClipboardFromIntermediate(page, workdir)` 读取 `正文_clean.html/txt` 写入剪贴板，避免逐平台打开飞书。
- 飞书复制前先点击正文中的**章节标题**（如“一、…”），不要点“备选标题”，否则可能只复制到备选标题块。

## 6. 删除正文开头重复的“主标题”和“备选标题”块

- 已统一为：在生成中转文件时用 `removeAltBlockFromHtml` 从 HTML 中删除（传入 `mainTitle` 时会先删除正文第一行重复主标题），**不再粘贴到编辑器后删除**。
- 各平台脚本不再需要“粘贴后删除主标题/备选标题”的步骤；若人工兜底遇到旧内容，直接重新生成 `正文_clean.html` 即可。

## 7. 发布频率

- 各平台发布频率/每日上限不同，**以对应平台 playbook 为准**，不要在本通用文档里硬编码。
- 通用建议：发布脚本应带重试；点击后等待“成功弹窗/跳转”，失败时先关闭残留弹窗再重试。

## 8. 后台/前台运行

- 所有自动化发布/改标题脚本默认后台（headless）运行。
- 需要观察浏览器操作时加 `--headed`，脚本会以前台有头模式启动 Chromium。
- 登录助手 `login.js` 是交互式工具，始终有头打开，不受 `--headed` 影响。

## 9. 链接收集

- 需要整理发布链接时，优先从各平台内容管理页抓取公开链接，而不是从日志里手抄。
- 若列表分页，用分页采集合并；若某页缺失，用搜索框短关键词补漏。
- 统一按 TSV 汇总：`文档链接\t平台\t标题名称\t发布链接`。
